BEM-VINDO CODE EXPLORERS.

A Code Explorers é uma comunidade de Jovens apaixanados por tecnologia, com foco no aprendizado prático, no crescimento coletivo no mundo da programação. Criamos este espaço para inspirar, desenvolver e conetar novos progrmadores que acreditam no poder do código para transformar o mundo.

Sobre Nós

QUEM SOMOS?

Somos estudantes,curiosos e futuros profissicionais da tecnologia.Nascemos com objectivos de unir jovens que estão começando ou querem aprofundar mais em areas como desenvolvimento Web, Redes de Computador, Cybersegurança, Mobile, Logica de programação.

O QUE FAZEMOS NA NOSSA COMUNIDADE?

Na Code Explorers valorizamos a prática por isso:

💻Criamos desafios de programação semanais para estimular a criatividade e os rassiocinos Logicos.

🌐Promovemos projectos colaborativos onde nossos menbros desenvolvem sistemas reais como Sites, Aplicativos ou feramentas uteis

🚀Organizamos livres mentorias e grupos de estudos com foco em fiferentes linguagens etecnologia. Abrimos espaço para que todos possam ensinar e aprender e crescer juntos.
